# DESARROLLO

-Desarrollar con patrones y estructuras con Clean Code.
-Cumplir principios SOLID.
-Cumplir el principio de responsabilidad única.
-Desarrolla siempre funcionalidades robustas y escalables, pensando principalmente en la seguridad.
-Desarrollar con patrones actuales de desarrollo.

# DOCUMENTACION

-Usa la carpeta /docs para mirar/estudiar/almacenar toda la documentación sobre la plataforma.
-Se debe mantener un orden estructural y organizado de carpetas para esta documentación.
-Se debe generar documentacion técnica de cada ruta de la aplicacion a medida que se van trabajando, esta documentación debe servir para posibles integraciones y para que los equipos de frontend puedas desarrollar sus funcionalidades, por tanto deben tener ejemplo, posibles respuestas, posibles errores..etc.
